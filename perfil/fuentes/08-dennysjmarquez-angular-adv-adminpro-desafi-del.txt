Resumen: This repository serves as a technical showcase for an **advanced Angular project** built as part of a comprehensive **MEAN stack** curriculum. The codebase features sophisticated front-end functionalities including **Google authentication**, **JSON Web Tokens (JWT)** for security, and **lazy loading** to optimize performance. Beyond the user interface, the project integrates an administrative dashboard with specialized tools for **file uploads, custom pipes, and route guards**. Developers can utilize the provided instructions to configure **environment variables**, connect to a separate backend repository, and manage the application using the **Angular CLI** for testing and production builds.

 archivo ubicado en: environments/
